## 按问题组织的学习路径

课程共 22 章。第 1–16 章构成完整主课程，第 17–22 章在其后继续展开工具机制深研，使用统一目录、来源索引和学习进度。

| 阶段                  | 你将解决的问题                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------- |
| 1–4：测量与运行时     | 如何定义工作量、单位、分母和归因？如何理解 Go 调度与 pprof 数据模型？                        |
| 5–10：剖析与调试工具  | 如何分析 CPU、分配、GC、锁竞争和执行追踪？什么时候需要 Delve、runtime/debug 与系统工具？     |
| 11–14：优化与工程实践 | 如何使用 PGO 和持续剖析？如何建立可复现、可反驳的性能结论？                                  |
| 15–16：项目实现与研究 | 成熟项目如何采样、展开栈、聚合与存储？研究工作实际解决了哪些问题，有什么评价边界？           |
| 17–22：机制与组合诊断 | eBPF 如何加载、验证和传输事件？pprof 如何赋权与生成报告？Perfetto 如何记录、保留和查询时序？ |

首次学习可以按章推进；查阅具体问题时，可以使用全文搜索、章节目录与可复制命令。研究章节包含方法、实现和评价分析，来源索引保留固定版本及阅读范围。

## 用图解和实验建立直觉

64 张图包括 39 组可播放机制图和 25 张新增原理图。机制图可以逐步观察或播放，共 160 个步骤；另有四组交互模型，分别解释 CPU 与墙钟、eBPF 环形缓冲区、pprof 聚合，以及 Perfetto 的保留策略。

贯穿实验使用一个墙钟为 20 ms 的合成请求。主线程消耗 8 ms CPU，工作线程消耗 15 ms CPU，总 CPU 因并行而达到 23 ms。课程将同一归属契约放入 pprof 与调度状态数据，核对总量、区间和工具实际输出，再分析每种证据无法回答的问题。

课程保留 62 道选择题、原课程的 35 道分析题和 16 个实验。网站提供答案解释、错题复习和学习进度；阅读页可跳转小节、展开全文或切换大字。进度保存在当前浏览器，可在“资料与设置”导出与导入。

## 读源码，也核对证据边界

主课程的前沿研究窗口为 **2021-10-02 至 2026-10-02**；工具机制材料查证于 **2026-10-04**。主要源码基线为 Go 1.25.0、Linux v6.12、libbpf v1.5.0、固定提交的 google/pprof 和 Perfetto v58.2。日期、源码版本与实际运行客户端分别记录，不将增订日期当作文献检索截止日期。

教材包含 168 项来源。对采样权重、递归与内联、差分、CO-RE、验证器、共享内存协议、增量状态和时钟转换等主题，结论均结合版本与适用条件解释。例如，验证器通过不意味着采集完整无偏；pprof 的聚合权重不能恢复事件时序；Perfetto 的缓冲区等待策略也有版本相关的失败路径。

配套实验中，一部分输入是明确标注的合成模型，真实工具用来校核解析、聚合与计算语义。eBPF 示例未进行特权内核加载，教材不会把离线源码审读当作生产采样或性能收益实测。
