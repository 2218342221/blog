<summary>在本地运行</summary>

需要 Node.js 22.12+，推荐 Node.js 24。

```bash
git clone https://github.com/2218342221/blog.git
cd blog
npm ci
BASE_PATH=/blog/ npm run dev
```

打开 [localhost:4321/blog/](http://localhost:4321/blog/)。构建与发布见[内容维护指南](docs/WRITING.md)。
