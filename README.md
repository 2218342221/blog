<details>
<summary>Run locally</summary>

Node.js 22.12+ (24 recommended).

```bash
git clone https://github.com/2218342221/blog.git
cd blog
npm ci
BASE_PATH=/blog/ npm run dev
```

Open [localhost:4321/blog/](http://localhost:4321/blog/). See the [writing guide](docs/WRITING.md) for building and publishing.
