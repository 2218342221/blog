1. 研究方法与检索范围

本综述采用问题驱动的定向检索、综述交叉检查与引文扩展，目标是解释 Agent Memory 的研究版图和证据现状。检索截至北京时间 2026-09-24，覆盖 2020—2026，重点关注 2025—2026。它不声称穷尽全部论文，也不将异构基准做元分析或统一排名。

  1. 用 CoALA、Memory Mechanism Survey、Memory in the Age of AI Agents 和 Memory in the Second Half 等综述交叉检查概念、研究路线和任务覆盖。
  2. 先按任务状态、事实证据和经验迁移界定研究问题，再比较组织粒度、读写机制、管理学习和内部载体；由这些问题推导多 Agent、多模态与长期运行的研究议程。
  3. 从代表论文的前后向引文扩展候选；通过 arXiv 标题/摘要检索和按日期排序结果补充新工作，阅读原始论文而非只依赖 related work 的二手概括。
  4. 用 ACL Anthology、PMLR、NeurIPS/IJCAI 正式页、OpenReview venueid 和论文元数据核对发表状态；只能取得接受说明时明确写出证据类型。
  5. 对关键方法读取机制、消融与限制，对关键基准核对任务规模、版本、指标、置信区间和计费边界；把独立复现作为对主张的补充检验。
  6. 工程能力依据厂商官方接口与架构文档，区分系统持久化、语义记忆、画像和技能；文档中的排名、延迟与宣传性断言不自动作为独立实测。
  7. 按相关性、机制清晰度、实验证据、正式发表与工程可核验性筛选；新颖性与论文数量不作为单独纳入理由。正文按任务连续性、事实有效性与经验迁移组织；表示、操作和学习分别作为比较维度。跨主体、跨模态与治理连接不同需求。

未纳入一般硬件内存与 KV 调度、与 Agent 决策无直接关系的同名 Memento 工作、缺少可核验来源的营销排名，以及只因标题含 memory 而不符合本文范围的论文。

机制细读的组织方式：状态管理组比较 MemGPT、ReadAgent、HiAgent、MEM1 与 MemAgent；证据组织组比较 RMM、A-MEM、HippoRAG 2、MemTree、LightMem、SimpleMem 与 Hindsight；经验组比较 Reflexion、ExpeL、ReasoningBank、AWM、Voyager、ACE 及近期技能学习；管理与载体组进一步核对 Memory-R1、MemSkill、MemEvolve、MemoryLLM、M+、Titans 和 MemGen。评测组独立检查记忆输入、执行过程、评分与费用，再回到各方法的设计主张。每篇的具体阅读范围及已读版本见文献条目。
